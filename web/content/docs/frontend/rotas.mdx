# Rotas — `web/src/app/`

Antes de criar uma rota nova, confira se ela já existe aqui.

---

## Observações

- A rota **`/comparador` foi cancelada** — sua funcionalidade foi absorvida pelo `/terminal` (Sprint 1). Ver [Roadmap](/docs/produto/roadmap).
- `/docs` é **bloqueada em produção** por padrão: o `next.config.ts` redireciona `/docs/:path*` para `/404` a menos que `ENABLE_DOCS=true`.
- Telas legadas (`DividendCalculator`, `SavingsSimulator`) **serão ocultadas** do nav no pivô; o código permanece em `terminal/`.

---

## Regras

- Antes de criar rota nova, cheque esta tabela.
- Server Components por padrão; `"use client"` apenas quando necessário.
- O client nunca chama Brapi/FastAPI direto — sempre via server action ou route handler.
