# Implementation Plan: Asset Detail Screen

**Branch**: `004-asset-detail` | **Date**: 2026-05-21 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/004-asset-detail/spec.md`

## Summary

Implement the `/asset/[ticker]` screen as a Next.js Server Component shell that fetches asset quote and radar data in parallel on the server, then passes initial history data to a Client Component chart. The price range toggle (1D/1M/1A) is handled client-side via a Server Action. Four new components are created under `src/components/asset/`, one Server Action is added to `src/lib/actions/market.ts`, and the existing placeholder page is replaced. No new npm packages are required — Recharts is already installed.

## Implementation Phases

### Phase A: Server Action (foundation — chart depends on this)

Create `web/src/lib/actions/market.ts`:
- `'use server'` directive at top of file
- Export `async function fetchAssetHistory(ticker: string, range: string): Promise<AssetHistoryData>`
  - Calls `getAssetHistory([ticker], range)` from `'@/lib/services/market'`
  - Returns the result directly (no transformation — client handles formatting)
- Import: `{ getAssetHistory }` from `'@/lib/services/market'`, `{ AssetHistoryData }` from `'@/types/market'`

### Phase B: Leaf Components (parallel — independent files)

All four components follow the same glass card pattern.

**`AssetHeader.tsx`** (Server Component — no `'use client'`):
- Props: `{ ticker: string; name: string | null; price: number | null; changePercent: number | null }`
- Outer: `<div className="relative overflow-hidden rounded-[2rem] border border-white/10 bg-[#1A1625]/40 p-6 shadow-[inset_0_1px_1px_rgba(255,255,255,0.15),inset_0_-2px_6px_rgba(0,0,0,0.6),0_10px_20px_rgba(0,0,0,0.4)] backdrop-blur-2xl">`
- Back link: `<Link href="/home" className="mb-4 flex items-center gap-1.5 text-xs text-[#F4F0FF]/50 hover:text-[#F4F0FF]/80">` with `<ArrowLeft size={14} />` icon + "Voltar"
- Ticker: `<h1 className="font-serif text-4xl text-[#F4F0FF]">{ticker.toUpperCase()}</h1>`
- Name: `<p className="mt-1 truncate text-sm text-[#F4F0FF]/60">{name ?? ticker}</p>`
- Price row: if `price` not null show `<p className="mt-4 font-serif text-3xl font-bold text-[#F4F0FF]">{price.toLocaleString('pt-BR', {style:'currency',currency:'BRL'})}</p>` + `<VariationBadge variation={changePercent ?? 0} />` else `<p className="mt-4 text-sm text-[#F4F0FF]/40">Dados indisponíveis</p>`
- `<GlassHighlight widthPercent={70} />`
- Imports: `Link` from `'next/link'`, `{ ArrowLeft }` from `'lucide-react'`, `{ VariationBadge }` from `'@/components/atoms/VariationBadge'`, `{ GlassHighlight }` from `'@/components/atoms/GlassHighlight'`

**`PriceChartClient.tsx`** (`'use client'`):
- Props: `{ ticker: string; initialHistory: AssetHistoricalPrice[]; isMarketOpen: boolean }`
- State: `const [range, setRange] = useState<'1d' | '1mo' | '1y'>('1mo')`
- State: `const [history, setHistory] = useState<AssetHistoricalPrice[]>(initialHistory)`
- State: `const [loading, setLoading] = useState(false)`
- Range change handler: async fn that calls `fetchAssetHistory(ticker, range)`, sets `history` from `result.results[0]?.history ?? []`
- `useEffect` on `range` change to call the handler (skip on initial render for `'1mo'` since `initialHistory` is pre-loaded)
- Chart data: map `history` → `{ date: formatDate(h.timestamp, range), close: h.close }`
  - For `'1d'`: `new Date(h.timestamp * 1000).toLocaleTimeString('pt-BR', {hour:'2-digit',minute:'2-digit'})`
  - For `'1mo'`/`'1y'`: `new Date(h.timestamp * 1000).toLocaleDateString('pt-BR', {day:'2-digit',month:'short'})`
- Outer glass card: same glass treatment as other cards
- Section label: `<p className="text-xs font-medium uppercase tracking-[0.2em] text-[#F4F0FF]/55 mb-4">Histórico de Preço</p>`
- Range toggle bar: 3 buttons ("1D", "1M", "1A") — active state: `bg-[#8B5CF6]/20 border-[#8B5CF6]/40 text-[#F4F0FF]`, inactive: `border-white/10 text-[#F4F0FF]/40 hover:text-[#F4F0FF]/70`
- If `history.length === 0` and not loading: `<p className="text-center text-sm text-[#F4F0FF]/40 py-8">Histórico indisponível</p>`
- If market closed and range === '1d': overlay pill "Mercado fechado"
- Chart: `<ResponsiveContainer width="100%" height={200}><LineChart data={chartData}><XAxis dataKey="date" tick={{fill:'#F4F0FF',fontSize:10,opacity:0.4}} axisLine={false} tickLine={false} /><YAxis domain={['auto','auto']} tick={{fill:'#F4F0FF',fontSize:10,opacity:0.4}} axisLine={false} tickLine={false} width={60} tickFormatter={v => v.toLocaleString('pt-BR',{minimumFractionDigits:2,maximumFractionDigits:2})} /><Tooltip contentStyle={{background:'#1A1625',border:'1px solid rgba(255,255,255,0.1)',borderRadius:'1rem',color:'#F4F0FF',fontSize:12}} formatter={(v: number) => [v.toLocaleString('pt-BR',{style:'currency',currency:'BRL'}),'Preço']} /><Line type="monotone" dataKey="close" stroke="#8B5CF6" strokeWidth={2} dot={false} /></LineChart></ResponsiveContainer>`
- Imports: `{ useState, useEffect }` from `'react'`, Recharts components from `'recharts'`, `{ fetchAssetHistory }` from `'@/lib/actions/market'`, `{ AssetHistoricalPrice }` from `'@/types/market'`, `{ GlassHighlight }` from `'@/components/atoms/GlassHighlight'`

**`RadarSection.tsx`** (`'use client'` — Recharts requires browser APIs):
- Props: `{ data: MarketRadarDataPoint[] | null }`
- Outer glass card + `<GlassHighlight widthPercent={60} />`
- Section label: `<p className="text-xs font-medium uppercase tracking-[0.2em] text-[#F4F0FF]/55 mb-4">Perfil do Ativo</p>`

**`AssetAnalysisCTA.tsx`** (Server Component — no `'use client'`):
- Props: `{ ticker: string }`
- Same visual as home `AnalysisCTA` but copy anchored to the specific ticker
- Heading: `<h2 className="font-serif text-2xl text-[#F4F0FF] mb-2">Analisar este ativo</h2>`
- Subtext: `<p className="text-sm text-[#F4F0FF]/60 mb-6">Entenda os sinais e movimentos recentes de {ticker.toUpperCase()} com contexto de IA</p>`
- CTA link: `<Link href={/analysis?ticker=${ticker}} className="inline-flex min-h-11 ...">Ver análise de {ticker.toUpperCase()}</Link>`
- Imports: `Link` from `'next/link'`, `{ GlassHighlight }` from `'@/components/atoms/GlassHighlight'`

### Phase C: Page Assembly

Replace `web/src/app/asset/[ticker]/page.tsx`:
1. Auth guard: `const session = await auth()` + redirect
2. Extract `ticker` from `params` (Next.js 15: `const { ticker } = await params`)
3. Parallel fetch: `Promise.allSettled([getMarketRadarData(ticker), getAssetHistory([ticker], '1mo')])`
4. From radar result: extract `name = radarData?.quote?.longName ?? null`, `price = radarData?.quote?.regularMarketPrice ?? null`, `changePercent = radarData?.quote?.regularMarketChangePercent ?? null`, `radarPoints = radarData?.data ?? null`
5. From history result: extract `initialHistory = historyData?.results?.[0]?.history ?? []`
6. Not-found guard: if both fetches failed → render "Ativo não encontrado" card with `<Link href="/home">`
7. Render vertical stack:
   - `<AssetHeader ticker={ticker} name={name} price={price} changePercent={changePercent} />`
   - `<PriceChartClient ticker={ticker} initialHistory={initialHistory} isMarketOpen={isMarketOpen()} />`
   - `<RadarSection data={radarPoints} />`
   - `<AssetAnalysisCTA ticker={ticker} />`

### Phase D: Type-check + Visual Verification

`pnpm type-check` → zero errors. Start `pnpm dev`, sign in, navigate to `/asset/PETR4` — header, chart (1M default), radar, CTA all render. Toggle range 1D and 1A — chart updates. Tap "Analisar este ativo" → lands on `/analysis?ticker=PETR4`.
