# Implementation Plan: Home Screen — Market Overview

**Branch**: `003-home-screen` | **Date**: 2026-05-20 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-home-screen/spec.md`

## Summary

Implement the `/home` market intelligence screen as a full Server Component that fetches market data in parallel from three existing service functions (`getMarketStatus`, `getMarketIndicators`, `getMultipleQuotes`). Six new presentational components are created under `src/components/home/`. A new utility module `src/lib/market-utils.ts` computes the temperature value and curates the ticker list. The screen is a vertical mobile-first stack with independent failure handling per section and a contextual analysis entry point. No new dependencies required.

## Implementation Phases

### Phase A: Utility Module (foundation — page depends on this)

Create `web/src/lib/market-utils.ts`:
- Export `CURATED_TICKERS: string[]` — 12 liquid B3 tickers
- Export `type TemperatureLevel = 'panico' | 'medo' | 'neutro' | 'ganancia' | 'euforia'`
- Export `type ComputedTemperature = { value: number; label: string; level: TemperatureLevel }`
- Export `function computeTemperature(ibovChange: number, vix: number | null): ComputedTemperature`
- Export `function formatSELIC(selic: PrimeRateEntry[]): { rate: string; date: string } | null`
- Export `function isMarketOpen(): boolean` — checks current UTC-3 time is weekday 10:00–17:00

### Phase B: Leaf Components (parallel — independent files)

All six components follow the same glass card pattern. Each is a Server Component (no `'use client'`):

**`TemperatureCard.tsx`**: Receives `ComputedTemperature | null`. Glass card + `GlassHighlight` + amethyst glow + `MarketTemperatureDial` atom (value, stateName) + temperature label below. Empty state if null.

**`IndexCard.tsx`**: Receives `name`, `price: number | null`, `changePercent: number | null`, `isOpen: boolean`. Glass card + index name in small caps + large price + `VariationBadge` + "Mercado fechado" pill if not open. Empty state if price null.

**`SELICCard.tsx`**: Receives `{ rate: string; date: string } | null`. Glass card + "Taxa SELIC" label + large rate in font-serif + small date line. Empty state if null.

**`MoverItem.tsx`**: Receives `ticker`, `name`, `price`, `changePercent`, `logoUrl?`, `href`. Full-width `<Link>` row — logo (36×36, fallback initials circle) + ticker/name + price + `VariationBadge`. Min-h-11. Hover: -translate-y-0.5.

**`MoversSection.tsx`**: Receives `title`, `icon: 'gainers' | 'losers'`, `movers: MoverDisplayData[]`. Glass card + section header (SVG triangle icon + serif title) + up to 3 `MoverItem` rows. Empty state if movers.length === 0.

**`AnalysisCTA.tsx`**: No props. Glass card + amethyst glow + `GlassHighlight` + serif heading + subtext + amethyst `<Link href="/analysis">` button. Copy frames AI as market signal interpretation, not conversation.

### Phase C: Page Assembly

Replace `web/src/app/home/page.tsx` placeholder:
1. Auth guard: `const session = await auth()` + redirect to `/auth/sign-in` if no session
2. Fetch data with `Promise.allSettled([getMarketStatus(), getMarketIndicators(), getMultipleQuotes(CURATED_TICKERS)])`
3. Extract + transform data: compute temperature, extract IBOVESPA + S&P 500, format SELIC, sort movers
4. Render vertical stack: heading → TemperatureCard → 2-col indices grid → SELICCard → MoversSection gainers → MoversSection losers → AnalysisCTA

### Phase D: Type-check + Visual Verification

`pnpm type-check` → zero errors. Start `pnpm dev`, sign in, navigate to `/home` — all 6 sections render with real or empty-state data.
